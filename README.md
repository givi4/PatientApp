- კლიენტების დემოგრაფია და აგრეგირებული სტატისტიკა;

## კლინიკური შეზღუდვები — მნიშვნელოვანი

ეს არის სამუშაო/პილოტური ვერსია და **არ არის მზად რეალური კლიენტების მონაცემებით კლინიკური ექსპლუატაციისთვის**. კლინიკური ინსტრუმენტების ზუსტი, ოფიციალურად დამტკიცებული ქართული კითხვები და სკორინგი არ იყო მოწოდებული. ჩაშენებული პუნქტები არის მოკლე პარაფრაზები და ზოგიერთ შემთხვევაში (PMQ-9, ED-15, RIS, AQ-10, OCI-R ზღვრები) ალგორითმი დამატებით სჭირდება ავტორთან/ოფიციალურ წყაროსთან დადასტურებას. კლინიკურ გადაწყვეტილებას ავტომატური ქულა ვერ ცვლის.

asQ-ის დადებითი შედეგი მოითხოვს უსაფრთხოების დამატებით კლინიკურ შეფასებას, მწვავე დადებითისას კი — გადაუდებელ რეაგირებას. QEEG დამოუკიდებლად არ ადგენს დიაგნოზს. პორტალი არ კითხულობს რუკის რიცხვებს OCR-ით; კლინიცისტმა თვითონ უნდა გადაამოწმოს და შეიტანოს მონაცემები. ინტერპრეტაციის თითოეული ასოციაცია არის პირობითი.

მრავალთერაპევტიანი გამოყენებისთვის Site-ის მფლობელმა უნდა მიანიჭოს თითოეულ პროფესიონალს ცალკე ავტორიზებული ანგარიში. **პირველი PIN-ის შექმნა** კონკრეტულ თერაპევტს აკავშირებს პირველ ავტორიზებულ ანგარიშთან; ამჟამად თითო ანგარიშს მხოლოდ ერთი თერაპევტი შეუძლია. რეალური კლინიკური გამოყენებისთვის დამატებით საჭიროა უსაფრთხოების, ნებართვების, შენახვის ვადების, აღდგენის, აუდიტისა და მონაცემთა დაცვის შეფასება.
